# AYAZ Frontend

Dijital pazarlama SaaS platformu için birleşik kontrol paneli.

## Kurulum

```bash
npm install
```

## Geliştirme

```bash
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.

## Ortam Değişkenleri

`.env.example` dosyasını `.env.local` olarak kopyalayın ve değerleri düzenleyin:

```bash
cp .env.example .env.local
```

| Değişken | Açıklama | Varsayılan |
|----------|----------|------------|
| `NEXT_PUBLIC_API_BASE` | Backend API base URL | `http://localhost:8000` |

## Üretim Build

```bash
npm run build
npm run start
```
